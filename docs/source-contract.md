# 来源资料契约

支持 PGN 标签、SAN、注释、NAG、RAV 嵌套变化、SetUp/FEN；不做棋力计算。game 按文件顺序 g1、g2 区分。move 的 value 含 game、branch、ply、san，主线 branch=main；第一层第一个白方第2回合变化用 main/2w:1，再嵌套以相同规则扩展，表达的是来源分支，不要求采用特定内部树实现。ply 是该局从初始局面计算的半回合序号，FEN 用它的 fullmove 与 side 确定。非法分支要记录位置与剩余范围，不能从主线继承错误局面。partial 文件的变化含非法着法。

每条已解释资料均可回到真实来源收件和具体位置。原始载荷与版本必须继续可查，不能以解析后的摘要替代原文。未列出的标准扩展允许明确标识未支持，不允许假称已解释。
